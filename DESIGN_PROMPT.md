# Промпт для генерации дизайна — «Pamildori» (Pomodoro Mini App)

> Скопируй всё, что ниже, и передай дизайн-ИИ (v0, Lovable, Claude, ChatGPT и т.п.).
> Цель — получить **HTML/CSS макет** интерфейса, по которому потом сверстают React-фронт.

---

## РОЛЬ И ЗАДАЧА

Ты — продуктовый UI-дизайнер и фронтенд-верстальщик. Создай **визуальный макет мобильного приложения** «Pamildori» — это таймер по технике Pomodoro, который работает как **сайт и как Telegram Mini App**.

Сделай **один самодостаточный HTML-файл** со всеми экранами, встроенным CSS (можно Tailwind через CDN) и заглушками анимаций. Реальная логика, бэкенд и JS-функциональность НЕ нужны — нужен внешний вид, структура и состояния.

---

## ОБЩИЙ ВАЙБ

- **Подача: мультяшная / иллюстрированная (cartoon).** Весь интерфейс — в милом мультяшном стиле: рисованные иллюстрации, мягкие округлые формы, дружелюбные пропорции, лёгкая «нарисованность» (как кадр из уютного мультфильма / иллюстрированной книги), а не плоский корпоративный UI и не фотореализм. Робот, окно, иконки, кнопки — всё нарисованное и живое.
- **Стиль: Dark Academia.** Мультяшность подаётся в приглушённой dark-academia палитре: тёплые тона, сепия, тёмное дерево, состаренная бумага, латунь/бронза, мягкие тени, книжная/уютная атмосфера. Винтаж + уют. То есть это «уютный мультфильм в эстетике тёмной академии», а не яркий детский мультик.
- Палитра-ориентир: глубокий тёмно-коричневый, графит, кремовый/пергаментный текст, акценты — приглушённое золото/охра, тёмно-бордовый, оливковый. Без кислотных и ярких неоновых цветов.
- Типографика: благородная — заголовки с засечками (serif, напр. что-то вроде Cormorant / Playfair / EB Garamond), тело — спокойный гротеск или humanist serif. Ощущение старой библиотеки.
- Скругления мягкие, тени тёплые и неяркие. Текстуры бумаги/дерева приветствуются (тонко).
- Мобильный формат: контейнер шириной ~390px (как телефон), всё помещается без горизонтального скролла.

## ⭐ ГЛАВНЫЙ ЭЛЕМЕНТ: РОБОТ-ТАЙМЕР

В центре главного экрана — **«живой» робот-таймер**:

- Квадратный милый робот со **скруглёнными углами**, дружелюбное лицо/экран (глаза, возможно «рот»-дисплей со временем).
- Робот реагирует на состояние и носит **костюмы**.
- За спиной робота — **ОКНО**, в котором видна сцена «время суток + погода».

### Костюмы робота (ОБЯЗАТЕЛЬНО рисовать как ОТДЕЛЬНЫЕ СЛОИ)
- **База** — обычный вид (день).
- **Ночной колпак** — треугольный колпак с бомбончиком (когда тема «ночь»).
- **Наушники** — когда играет плейлист.
- Костюмы **комбинируются**: ночь + плейлист = колпак И наушники одновременно. Поэтому каждый костюм — отдельный слой (`<div>`/`<svg>` поверх базы), а не цельная картинка.

### Состояния/анимации робота (сделай хотя бы статичные варианты + лёгкие CSS-анимации-заглушки)
- `idle` — спокойно «дышит», иногда моргает.
- `focus-running` — сосредоточен, идёт работа.
- `break` — расслаблен.
- `complete` — радуется (искорки/улыбка) при завершении сессии.
- `dozing` — дремлет, если долго не трогать (Zzz).
- `headphones` — в наушниках (плейлист играет).
- `nightcap` — в ночном колпаке (ночь).

## 🪟 СЦЕНА ЗА ОКНОМ — СЛОИСТЫЙ ПРОЦЕДУРНЫЙ РЕНДЕР (ВАЖНО)

Сцена в окне = **время суток × погода**. НЕ рисуй 20 отдельных фонов. Собери сцену **слоями**, чтобы фронт мог менять их независимо:

**Слой 1 — небо (время суток):** градиент, меняющийся по циклу:
`ночь → сумерки → рассвет → день → закат → сумерки → ночь`
(дай 5–6 вариантов градиента неба как CSS-классы/переменные).

**Слой 2 — погода (поверх неба):** ясно / облачно / дождь / гроза (дождь + молнии).
Облака, капли дождя, вспышки молний — реализуй как отдельные элементы с CSS/SVG-анимацией поверх неба.

**Правило комбинации:** погода затемняет/осветляет сцену. Напр. «день + облачно» = чуть темнее ясного дня.

> В разметке пометь слои понятными классами и `data-`атрибутами, напр.:
> `data-timeofday="day|night|dawn|dusk|twilight"` и `data-weather="clear|cloudy|rain|storm"`.
> Это нужно, чтобы фронт переключал состояния, а не подменял картинки.

## ТЕМЫ (управление спрятано в Настройках)

- **День** / **Ночь** / **Авто-по-времени** (тема меняется по часам устройства через цикл времени суток).
- **Погода — ручной выбор** в настройках: ясно / облачно / дождь / гроза.
- Тема меняет и палитру интерфейса, и сцену за окном, и костюм робота.
- Все переключатели тем/погоды/костюмов живут **внутри экрана Настроек**, не на главном.

## ЭКРАНЫ И ФУНКЦИОНАЛ (нужны ВСЕ)

Внизу — **таб-бар навигации** (иконки в стиле dark academia):
`Таймер · Задачи · Статистика · Плейлист · Настройки`

### 1. Таймер (главный)
- Робот + окно по центру.
- Крупный **дисплей оставшегося времени** (mm:ss).
- **Пресеты интервалов:** кнопки `5 / 15 / 30 / 60 мин`.
- **Ручной ввод** произвольного времени.
- Переключатель режима: **Фокус / Короткий перерыв / Длинный перерыв**.
- Кнопки: **Старт / Пауза / Сброс / Пропустить**.
- Индикатор текущего цикла (напр. 🍅🍅🍅○ — сколько помодоро до длинного перерыва).
- Если выбрана активная задача — показать её название над таймером.

### 2. Задачи (to-do)
- Список задач, добавление новой (поле ввода).
- У задачи: название, **оценка в помидорах** (напр. 3 🍅), сделано/всего, чекбокс «выполнено».
- Возможность выбрать **активную задачу** для текущего таймера.
- Свайп/кнопки: редактировать, удалить.

### 3. Статистика
- Завершённые **помодоро** и **фокус-минуты**.
- **Стрик 🔥** (сколько дней подряд) и **дневная цель** (прогресс к цели за сегодня).
- Простые **графики по дням** (бар-чарт за неделю/месяц).
- Итоги: сегодня / неделя / всего.

### 4. Плейлист (Telegram)
- Список аудио-треков пользователя (каждый юзер — свой плейлист).
- Подсказка: **«Чтобы добавить трек — отправь аудио боту в Telegram»** (треки добавляются командой/отправкой в бота, не из приложения).
- **Плеер** с контролами: play/pause, следующий/предыдущий, **перемешать**, **повтор**, **громкость**, прогресс трека.
- Когда трек играет — робот надевает **наушники**.
- Отдельный блок **«Эмбиент-звуки»**: дождь / камин / кафе / white noise (встроенные, с переключателями и громкостью; можно включать вместе с музыкой/как фон).

### 5. Настройки
- Длительности: фокус, короткий перерыв, длинный перерыв, «длинный перерыв каждые N помодоро».
- Авто-старт перерывов / авто-старт фокуса.
- Звук по окончании (вкл/выкл), выбор сигнала.
- **Тема:** День / Ночь / Авто-по-времени.
- **Погода:** ясно / облачно / дождь / гроза (ручной выбор).
- **Уведомления бота** по окончании таймера (вкл/выкл).
- Дневная цель (кол-во помодоро).
- Профиль (имя/аватар из Telegram).

## КОНТЕКСТ: ТЕЛЕГРАМ-БОТ (для понимания продукта)

Приложение связано с Telegram-ботом. Функционал бота:
- `/start` — приветствие, кнопка открыть Mini App.
- **Добавление аудио в плейлист** — пользователь присылает боту аудиофайл, тот сохраняет его в личный плейлист (через `file_id`).
- **Уведомления** — бот присылает сообщение «помодоро завершён 🍅», даже если мини-апп закрыт.
- Авторизация — через Telegram (данные пользователя берутся из Telegram).

Это контекст; отдельные экраны чата бота рисовать не нужно — только при необходимости показать подсказки в приложении (как добавить трек и т.п.).

## ФОРМАТ РЕЗУЛЬТАТА (как отдать)

1. **Один HTML-файл**, самодостаточный (CSS внутри `<style>` или Tailwind CDN).
2. Все экраны в одном файле — либо секциями друг под другом, либо с простым переключением табов.
3. **Чёткая структура и имена классов**, чтобы легко разложить на React-компоненты.
4. **Слои сцены и костюмов — отдельными элементами** с `data-`атрибутами (`data-timeofday`, `data-weather`, костюмы — отдельные слои поверх робота).
5. Покажи **разные состояния робота** (хотя бы в виде нескольких статичных вариантов рядом или переключателем).
6. Используй **CSS-переменные** для палитры/тем (чтобы темы переключались сменой переменных).
7. Лёгкие CSS-анимации-заглушки (дыхание робота, моргание, дождь, мерцание молнии) — приветствуются.
8. Комментарии в коде, поясняющие слои и состояния.

**Не нужно:** настоящей логики таймера, реальных данных, бэкенда, JS-фреймворков. Только разметка, стили, состояния и анимации-заглушки.
